# 高级送货单二维码生成器 (Advanced QR Code Generator)

专为送货单管理设计的批量二维码生成工具，支持双模式生成、智能校验、**云端配置同步**与精细化 Excel 导出格式。

## ✨ 核心功能特性

### 1. 云端配置同步与管理员面板 (Cloud Sync) ☁️
*   **集中化管理**: 管理员可通过隐藏的管理面板修改“客户名称、地址、联系人、电话”等元数据。
*   **Gitee API 集成**: 报表配置信息实时存储在 Gitee 云端，修改后全员即时同步，无需开发介入。
*   **隐藏入口**: 快速点击页面左上角 **Logo 3 次** 即可唤起“全局同步管理中心”。

### 2. 双模式一体化界面
*   **送货单表头 (DN Header)**: 包含 DN No., Vendor ID, PO No.，支持单独管理。
*   **送货单明细 (DN Detail)**: 包含 Full PO No., Qty, Unit, Unique ID, PN, 产品净重, 产品总重, 备注。
*   **统一操作**: 只需点击一次生成，即可同时渲染表头和明细的所有二维码！

### 3. 智能数据输入 (Smart Paste)
*   **启发式粘贴解析**: 支持直接从 Excel 复制数据粘贴。系统能自动识别 Tab/空格，并根据关键字判断数据归属。
*   **单位自动标准化**: 如检测到单位为 `PCS`，系统会自动转换为标准码 `PC`。
*   **预定义单位菜单**: 网页与 Excel 均内置 `Kg`, `M`, `PC`, `ROLL`, `SET` 选择。

### 4. 打印级精排报表导出 (A4 纵向) 🚀
*   **Excel 排版优化**: 
    *   **表头二维码**: 尺寸 68x68 像素，绝对居中锚定。
    *   **防遮挡元数据**: 客户信息采用 A 列溢出显示技术，彻底解决文本截断问题。
    *   **原子级对位**: 利用原生 EMUs 计算，确保所有二维码在单元格内 100% 绝对居中。

## 🛠️ 使用指南

### 管理员配置
1.  **进入面板**: 连续点击左上角 Logo 图标 3 次。
2.  **首次设置**: 在“高级设置”中填入您的 Gitee 私人令牌和仓库路径 (`owner/repo`)。
3.  **同步**: 修改完客户信息后点击“立即推送到云端”，全公司同事刷新页面即可看到更新。

### 日常使用
1.  **输入数据**: 可选择“下载模板”导入，或直接在紫色框内 `Ctrl+V` 粘贴。
2.  **生成**: 点击“批量生成”按钮。
3.  **导出**: 点击“导出送货单明细表”获取完美排版的 Excel 报表。

## 📂 文件结构说明

*   `index.html` - 主界面（含 1850px 超宽布局与管理员弹窗）
*   `script.js` - 核心逻辑（含 Gitee API 同步、3次点击监听、单位转换）
*   `enhancements.js` - Excel 高级报表驱动（含二维码 EMU 居中逻辑）
*   `report-config.json` - 云端配置文件模板（存放在 Gitee 仓库中）
