# 高级送货单二维码生成器 (Advanced QR Code Generator)

专为送货单管理设计的批量二维码生成工具，支持双模式生成、智能校验与精细化 Excel 导出格式。

## ✨ 核心功能特性

### 1. 双模式一体化界面
*   **送货单表头 (DN Header)**: 包含 DN No., Vendor ID, PO No.，支持单独管理。
*   **送货单明细 (DN Detail)**: 包含 Full PO No., Qty, Unit, Unique ID, PN, 产品净重, 产品总重, 备注。
*   **统一操作**: 只需点击一次生成，即可同时渲染表头和明细的所有二维码！

### 2. 智能数据输入 (Smart Paste)
*   **启发式粘贴解析**: 支持直接从 Excel 复制表头或明细数据并在同一框内粘贴。系统不仅能自动识别 Tab 或空格分隔符，还可根据关键字自动判断数据归属。
*   **智能单位转换**: 粘贴或导入时，如检测到单位为 `PCS`，系统会自动标准化为 `PC`。
*   **预定义单位菜单**: 网页与 Excel 模板均内置 `Kg`, `M`, `PC`, `ROLL`, `SET` 下拉选择。

### 3. 严格且灵活的数据校验 🛡️
*   **宽容查重机制**: 实时检测重复数据。但只要**流水号 (Unique ID)** 不同，即允许并存，满足多箱同料的需求。
*   **重量逻辑锁**: 强制校验 **产品总重必须大于产品净重**。系统会自动提取数值进行比对，不符合逻辑将禁止生成二维码。
*   **必填项检查**: 采购单号（需符合包含两个`-`的规范）、数量、零件号、净重及总重均为强制校验项。

### 4. 打印级精排报表导出 (A4 纵向) 🚀
*   **超宽屏优化**: 网页端采用 **1850px** 超宽容器及极致压缩的列宽设计，确保 11 列数据在大多数屏幕下无需滚动条即可完整展示。
*   **Excel 排版黑科技**:
    *   **表头二维码**: 置顶于 Row 1-4，锚定在 H 列，尺寸 68x68 像素，方正美观且不遮挡下方信息。
    *   **防遮挡元数据**: 客户名称/地址/联系人采用 A 列拼接技术，利用右侧空白列溢出显示，彻底解决单元格缩窄导致的文本截断。
    *   **元数据位移**: 送货单号、日期、电话整体右移至 G/H 列，并进行加粗处理，视觉重点更清晰。
    *   **明细布局**: 自动在单位与二维码之间插入净重、总重列，备注列位于末尾。
    *   **原子级对位 (EMUs)**: 利用原生 EMUs 计算，确保二维码在单元格内 100% 绝对居中。

### 5. 跨端 PWA 应用级支持 📱
*   **安装到桌面**: 支持通过 Service Worker 安装为本地 App。
*   **全脱机工作**: V36 版本缓存机制，保障即便在弱网环境下也能稳定生成。

## 🛠️ 使用指南

### 快速开始
1.  **输入数据**:
    *   *方法 A (模板)*: 点击“下载模板”，在本地使用下拉菜单填好后“导入数据”。
    *   *方法 B (快贴)*: 在 Excel 选中明细（支持 PO, Qty, Unit, PN, Net, Gross, Remk），在紫色框内 `Ctrl+V`。
2.  **生成**: 点击红色/紫色“批量生成所有二维码”按钮。
3.  **结果导出**:
    *   📥 **Excel 明细导出**: 点击“导出送货单明细表”。
    *   📦 **ZIP 图像包**: 一键打包下载全部图码原文件。

## 📂 文件结构说明

*   `index.html` - 主界面（采用暗色玻璃磨砂 UI 与 1850px 宽屏布局）
*   `styles.css` - 核心样式（包含深色垂直分割线标题、列宽微调逻辑）
*   `script.js` - 核心逻辑（包含数字提取比较、PCS 自动转换、智能粘贴解析）
*   `enhancements.js` - Excel 高级报表驱动（包含 EMU 居中、A 列拼接溢出、H 列 QR 锚定逻辑）
